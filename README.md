# Ketey IDE Education

Learn to code in Ketey IDE with fun and interactive lessons!

## Welcome to Ketey IDE Education!

These lessons will teach using the Ketey IDE ui up to creating your own extensions.

## Why Learn Ketey IDE?

Ketey IDE is a visual blocked based language that is built off Snail IDE. It can be used as a programming language or a tool to help you learn other programming languages. It even has AI tools such as ChatGPT which can be used without an OpenAi account to create even cooler projects.
